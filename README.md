# 🌾 GramamMart (గ్రామం మార్ట్)

GramamMart is a web application designed for rural villages to order groceries and daily essentials with a localized Telugu interface and instant order alert integrations.

## 📁 Repository Layout

- `client/`: Contains frontend application code (`index.html`, `style.css`, `app.js`).
- `server/`: Contains backend Express API service (`server.js`, `package.json`, `.env`).
- `README.md`: Project description and installation guide.

## 🚀 Quick Setup Instructions

1. **Start Backend Server:**
   ```bash
   cd server
   npm install
   npm start
